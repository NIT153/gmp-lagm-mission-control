# gmp-lagm-mission-control
GeoMorphPyramid Mission Control v0.1 è una dashboard tecnico-scientifica per il progetto LAGM, dedicata all’identificazione falsificabile di candidati morfologici piramidali tramite DEM/DTM, PSI, QGIS e validazione GIS. Il sistema non dichiara scoperte archeologiche: genera candidati da verific con controlli geomorfologici, multisens e rev esperta.
