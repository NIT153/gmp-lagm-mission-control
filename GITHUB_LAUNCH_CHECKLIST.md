## Attivazione Pages

1. Aprire il repository su GitHub.
2. Entrare in **Settings -> Pages**.
3. Impostare:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / root
4. Salvare.
5. Attendere alcuni minuti.
